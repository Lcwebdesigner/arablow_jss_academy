# Arablow JSS Academy

A modern, responsive e-learning and examination platform designed for Junior Secondary School (Grade 7–9) students in Kenya.

## Features
- **JSS Curriculum:** Coverage for 10+ core subjects including Math, Science, English, Kiswahili, and ICT.
- **Online Exams:** Interactive, timed online examinations for assessment.
- **Results Portal:** Quick access to student performance and grades via student number.
- **Learning Resources:** Study notes, summaries, and revision materials.
